## 1. 서론
* 문제: 로봇 팔(UR5)이 손목 depth 카메라만 보고 테이블 위 물체를 평행 그리퍼(RG2)로 집어 올린다.
* 질문: 같은 MDP 에서 **표 기반 Q-learning** 과 **함수 근사 DQN** 은 학습 속도·최종 성능·필요 자원·안정성에서 어떻게 다른가?
* 기여: [예) 물리 기반 시뮬레이터 구성, 상태 표현 3종 비교, 보상 셰이핑의 함정 분석 …]

## 3. MDP 정의
* **상태 S**: 손목 depth → 물체 분할 → (dx, dy, dz, yaw). Q-learning: 구간화 [7×7×6×7+1 = 2059] 상태.
  DQN: [연속 특징 7차원 / 원시 depth 64×48].
* **행동 A**: x±, y±(1 cm), z±(3 cm), yaw±(15°), grasp — 9개
* **보상 R**: 성공 +10, 실패 −3, 충돌 −2, 스텝 −0.05, 셰이핑 γ_sΦ(s′)−Φ(s)
* **전이 P**: IK + 실행 오차(σ = 2 mm) + 물리 판정 → 확률적
* γ = 0.99, 최대 60 스텝
